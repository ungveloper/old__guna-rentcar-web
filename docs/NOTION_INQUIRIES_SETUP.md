# 건아렌트카 — 상담 요청 → Notion 데이터 소스 연동

## 현재 상태

코드는 실제 Notion 데이터 소스에 새 페이지를 생성하도록 준비되어 있습니다. **토큰 및 대상 ID는 제공되지 않아 아직 실데이터 저장이 연결된 상태가 아닙니다.** 자격 증명을 GitHub에 넣지 마세요. ChatGPT의 Notion 플러그인은 필요하지 않습니다.

## 연결 순서

1. Notion에서 상담 요청 전용 데이터베이스를 만들고, 데이터 소스의 제목(Title) 속성을 1개 이상 포함합니다. 자동화는 "새 페이지 생성"을 트리거로 연결합니다.
2. https://www.notion.so/profile/integrations 에서 내부 통합(Integration)을 만들고 페이지 읽기/쓰기 권한을 부여합니다.
3. 데이터베이스의 연결(Connections) 메뉴에서 해당 통합에게 데이터 소스 액세스 권한을 부여합니다.
4. **Data Source ID**를 구합니다. 2025-09-03 API에서는 Database ID와 Data Source ID가 다릅니다. 필요하면 `GET https://api.notion.com/v1/databases/{DATABASE_ID}`로 응답의 `data_sources[].id`를 확인합니다. 이때 Authorization/Notion-Version 헤더가 필요합니다.
5. Mac 프로젝트 루트의 `.env.local`에 두 환경변수를 작성합니다:

   ```dotenv
   NOTION_API_KEY=ntn_실제_연동_토큰
   NOTION_DATA_SOURCE_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
   ```

6. Vercel 등의 배포 환경에서도 같은 이름으로 환경변수를 **서버 전용**으로 설정한 뒤 재배포합니다. 절대로 `NEXT_PUBLIC_` 접두사를 붙이지 마세요.
7. `npm run dev`로 접수 테스트를 하고, 노션 새 페이지가 생성됐는지 확인합니다. **성공 알림은 실제 Notion 생성 API가 성공하고 페이지 ID를 반환한 경우에만 나타납니다.**

## 생성되는 페이지

- 데이터베이스의 실제 Title 속성 이름을 API에서 읽어 제목을 작성합니다.
- 이름, 전화번호, 서비스 유형, 관심 차량, 이용 시작 희망일, 메모, 접수 시간, `상담 요청은 예약 확정이 아님` 안내를 새 페이지의 본문 블록으로 저장합니다.
- 고객이 입력한 휴대전화와 이름을 서버 로그 또는 응답에 담지 않습니다.

## 공개하기 전에 반드시 확인할 사항

- 개인정보 수집·이용 고지에서 **수집 목적, 수집 항목, 보관 기간, 파기 방법, 문의처, Notion 이용/국외 이전 여부** 등 적용 법률상 필요한 항목을 확인하고 완성하세요. 이 패치가 법적 개인정보처리방침을 대체하지 않습니다.
- 외부에 공개될 폼에는 WAF/Turnstile 등의 봇 차단과 **공유 저장소 기반 속도 제한**을 추가하는 것이 좋습니다. 기본 API에는 출처 확인·허니팟·입력 제한 및 프로세스 단위 간단 제한이 있으나 서버리스 다중 인스턴스 전체 제한은 아닙니다.
- 노션 자동화는 **접수 성공 시 새 페이지 생성**을 기준으로 후속 액션을 등록하세요. Notion 자동화 자체는 이 패치가 생성하거나 실행하지 않습니다.
- Notion 연결 실패 시 API는 503/502를 반환하고 Sonner는 실패 알림을 띄웁니다. **성공으로 표시하지 않습니다.** 전화 문의 버튼은 계속 작동합니다.
